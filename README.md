# Twin Stars Studio

Windows 设计工作台与无限画布。

## 下载

[下载最新 Windows x64 安装包](https://github.com/ThereisnoholidayonFriday/twin-stars-studio-releases/releases/latest)

在版本页下载 `Twin-Stars-Studio-…-x64-Setup.exe` 并安装。`latest.yml` 和 `.blockmap` 由软件更新使用，无需手动打开。`SHA256SUMS.txt` 用于核对安装包。

## 接收更新

安装 0.1.1 或更新版本后，软件会在启动时及使用期间检查新版本。也可以打开「设置与连接 → 版本与更新」手动检查、下载并重启安装。

更新前会保存并备份当前项目；项目和素材仍保存在本机。用户下载和检查更新无需 GitHub 账号或令牌。

原始 0.1.0 测试版尚无更新模块，需要手动安装一次新版本。网页项目迁移：先在网页导出备份，再在桌面版工作空间导入。

## 测试版范围

当前为 Windows x64 内部测试版，尚未进行 Windows 发布者代码签名。AI 生图仍为演示；Hermes Agent 需另行部署。本仓库仅用于安装包与更新分发，源码独立保存在私有仓库。

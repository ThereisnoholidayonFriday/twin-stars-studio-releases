# Twin Stars Studio

文件驱动的本地视觉制作工作台。本文对应 0.1.82。

[下载最新版本](https://github.com/ThereisnoholidayonFriday/twin-stars-studio-releases/releases/latest)。联网安装器小于 50 MB，安装时联网下载并校验完整组件。

上传产品和图需 → 理解资料 → 完整方案 → **方案确认** → 代表样图与复核 → **样图确认** → 剩余图位制作与复核 → 定向返修 → 采用、导出与复用。

资料、可读内容、工作文档和结果分别落盘。`图需.json` 是图位规格与文案的结构化来源；产品档案、规则和提示词以 Markdown 保存。模型修改形成新版本，原件和旧图片保留。未知的生图请求先核对，不能自动重发。

三栏工作台将项目会话、专项上传、图需表格、图片版本、文件编辑与差异放在同一项目。资产库、品牌库、提示词库与文档型 Skill 保持独立入口，引用固定版本。Skill 附带脚本不执行。

保留 Electron、现有模型兼容协议、凭据加密及用户自主更新。旧画布、外链文件夹、群聊、微信、MCP/Lovart、通用 HTTP 工具、Max 执行器、图片图层编辑器和 PSD/PSB 导出已退出运行及打包路径。

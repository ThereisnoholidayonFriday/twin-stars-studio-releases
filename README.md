# Twin Stars Studio

把资料、对话、画布和图片制作放进同一个 Windows 工作空间。

Twin Stars Studio 面向电商视觉、产品图和日常设计工作：用 **ChatStars** 讨论需求与生成图片，在 **无限画布** 中组织参考图、文本和处理节点，用 **项目总管** 按步骤读取资料、研究、规划、制作与审核。项目主要保存在本机，AI 功能连接你自己配置的模型服务。

[下载 Windows x64 最新版本](https://github.com/ThereisnoholidayonFriday/twin-stars-studio-releases/releases/latest) · [使用说明](docs/user-guide.md) · [当前限制](docs/user-guide.md#当前限制)

## 可以做什么

| 模块 | 主要用途 |
| --- | --- |
| ChatStars | 项目对话、多模型成员、图片与文档引用、对话或生图任务 |
| 无限画布 | 拖入图片/TXT、文本与图片连线、批量生成、本地图片处理、撤销重做与历史 |
| 项目总管 | 读取关联资料、保留原文与来源、分步确认/修订、失败续读、视觉制作流程 |
| 规则与学习 | 项目默认本地学习、保留明确关闭设置、反馈来源核对、本地检索、执行检查及规则库备份 |
| 素材与品牌 | 项目素材、跨项目资产分类/文件夹/标签、品牌手册、字体与标志资料 |
| 图片编辑 | 图层与文字、裁切、调色、AI 编辑、去背景、拆分图层、PNG/PSD/PSB 导出 |
| 本机工作空间 | 项目和子项目管理、自动保存、项目导入导出、由用户选择安装的版本更新 |

AI 任务需要兼容的服务地址、模型和 API Key，调用费用由服务商收取。连接成功只代表接口可访问；看图、生图、编辑与局部重绘需要分别配置并验证能力。实际生成质量和尺寸仍取决于模型，软件会记录失败和不符合要求的结果。

## 第一次使用

1. 在下载页选择安装程序。0.1.71 提供约 0.32 MB 的 `Online-Setup.exe`，安装时下载完整程序；离线安装选择 `Twin-Stars-Studio-版本号-x64-Setup.exe`。
2. 打开 **设置与连接 → 模型服务 → 添加模型**，填写服务信息、勾选能力并保存配置。
3. 新建项目。直接对话可用 ChatStars；整理节点用无限画布；成套制作可从 Max/项目总管进入。
4. 上传图片和文档，或关联本机资料文件夹，再输入本次任务。
5. 保存结果。换电脑前阅读使用说明中的备份章节，另行保存原始附件。

## 安装与更新

目前提供 Windows x64 测试版。安装后无需自行安装 Node.js。提供约 0.32 MB 的联网安装器，完整程序仍约 620 MB，功能保留；准确大小以 Release 附件为准，详见[联网安装说明](docs/online-installer.md)。当前没有 Windows 发布者代码签名。

新版本发布后，运行中的客户端会定期检查并显示更新内容。你可以选择 **暂不更新 / 立即更新**；安装前先保存并建立项目恢复点，失败时不会继续重启。也可在 **设置与连接 → 版本与更新** 手动检查。下载不需要 GitHub 账号或令牌。

`latest.yml` 和 `.blockmap` 供软件自动更新使用；`SHA256SUMS.txt` 用于核对安装包。原始 0.1.0 测试版需手动安装一次新版本。

## 能力边界

- 支持手动 MCP/API 工具连接与调用，以及 Hermes 微信按项目授权的任务桥接；详见[配置与使用说明](docs/connectors-and-remote-tasks.md)。使用前需配置自己的工具服务或 Hermes 微信通道。
- 工作空间保存在本机，不提供云同步或多人实时协作。
- 项目 JSON 导出保留项目结构、图片与可读取文本，不包含完整原始文档、字体包和所有后台任务档案。
- 迁移可用 .twinstars.zip 项目资料包携带本机可读取的原始附件；仍须核对缺失文件提示，并另行备份源目录和完整工作空间。
- PSD/PSB 有结构及像素回读测试，尚未完成真实 Photoshop 打开验收；长流程也不能用模拟测试替代真实模型的商业成品验收。

详细步骤、快捷键、资料恢复和常见故障见 [使用说明](docs/user-guide.md)。

# 小型联网安装包

0.1.61 提供约 **0.32 MB** 的联网安装器，低于 **50 MB** 首次下载上限。运行后下载约 **617 MB** 完整程序，再进行校验和安装；准确大小以该 Release 附件为准。

## 用户如何安装

在 GitHub Release 选择 `Twin-Stars-Studio-版本号-x64-Online-Setup.exe`。运行后按提示下载完整程序；校验通过后打开原来的完整安装向导，再选择安装目录。功能、项目资料位置和现有更新弹窗保持一致。

联网安装器只缩小首次下载的文件，首次安装仍需要下载完整程序，安装后的磁盘占用也不会因此缩小。下载和安装需要临时空间；网络受限或需要离线安装时，选择同一 Release 中名称不含 `Online` 的完整 `Setup.exe`。

下载目标固定为该版本公开 Release 下的完整安装包，不使用会变化的“最新版本”下载地址。下载失败可重试，损坏文件会停止安装。下载及 SHA-512 校验完成前不会运行完整安装器，因此不会提前卸载旧版。当前仍未配置 Windows 发布者签名，不将文件完整性校验说成发布者身份认证。

## 更新方式

安装器只缩小首次下载的入口，完整程序下载量及安装占用保持不变。软件自动更新仍使用完整安装器，由用户选择暂不更新或立即更新。准确大小和校验值见对应 Release 的 online-installer.json 与 SHA256SUMS.txt。

# 工具连接器与微信本机任务

本页对应 0.1.61 新增功能。连接器与桥接已进行内部沙盒验证，真实微信通道需使用自己的配置联调。

## MCP / HTTP API

打开“设置 → 工具与连接器”，添加或编辑配置。MCP 支持 Streamable HTTP URL，以及 `{"command":"程序路径","args":["参数"]}` 格式的 stdio。远程 URL 必须使用 HTTPS；本机回环地址可使用 HTTP。stdio 连接会启动所填程序，只使用自己认可的命令和来源。

保存配置后点击“连接并发现工具”。访问令牌在连接面板专用密码框中输入，以 Bearer 头发送；只保存在本次会话内存，不写入项目、导出文件或连接配置。stdio 不支持在配置里保存 env/cwd；不得把密钥塞进命令参数。

MCP 连接后显示服务实际返回的工具、说明及参数格式。选择工具，填写 JSON 对象，核对内容并勾选确认，再点击“执行工具”。这是手动调用面板，不会把连接器自动交给聊天模型执行。配置变化后需重新连接，离开此设置页会断开工具会话。

HTTP API 支持固定 URL 的 GET 查询和 POST JSON，使用相同的确认步骤。显示“地址已校验”只表示配置就绪，不表示服务已通过验证。GET 参数使用文本、数字、布尔值等简单类型；暂不支持任意请求头、OAuth 登录、文件上传或流式业务协议。

执行期间阻止重复提交；超时或网络错误不自动重试。服务端可能已收到请求，需先核对结果再重试。API 请求最长 30 秒、响应最多 4 MB；MCP 单次工具调用最长 120 秒。工具结果是外部服务返回的数据，请自行检查。

## 微信通过 Hermes 操作已有任务

1. 在项目里启动总管，使项目有已保存的任务。
2. 打开“设置 → 微信连接设置”，配置并检测自己的 Hermes 微信通道。将私聊策略设为白名单，填写授权用户，并应用到 Hermes。
3. 在“微信操控本机任务”选择允许操作的项目。默认只有查询和暂停；确需恢复已暂停任务时，单独勾选允许恢复。恢复可能继续调用原有付费模型。
4. 开启桥接，将界面提供的 YAML 片段合并到同一台电脑的 Hermes profile `config.yaml`，保留原有配置。点击“复制令牌环境变量”，保存到该 profile 的 `.env`，然后重启 Hermes。
5. 通过已授权的微信用户要求 Hermes 查询或暂停所选任务。任务 ID 的可选范围会出现在工具参数中。恢复只接受已暂停任务；新建任务、审批方案等仍在桌面完成。

配置片段使用 `mcp_servers`、Bearer 头、环境变量引用及 `trust: untrusted`；不启用工具并行调用。参考 [Hermes 官方 MCP 配置说明](https://hermes-agent.nousresearch.com/docs/reference/mcp-config-reference)。请保留 Hermes 的写操作确认设置。

桥接只监听 `127.0.0.1`，使用随机端口与随机会话令牌，拒绝浏览器 Origin 请求。不会直接对互联网开放；不同电脑的 Hermes 不能直接访问本机回环地址。本实现不负责配置跨机隧道。

微信用户身份及白名单由 Hermes 验证；Twin Stars 按持有令牌的 Hermes 会话校验任务范围。因此应保护令牌，并确认 Hermes 的白名单已实际应用。修改微信白名单后，也应关闭并重新开启桥接。不要将令牌发到聊天群或提交 GitHub。

写操作必须提供唯一 `requestId`；同一会话内重试沿用原 ID，不会重复执行。同一 ID 不能改用于另一操作。每次会话最多保留 1,000 个写操作回执，满后需在桌面重新开启。关闭桥接会撤销令牌；已经开始的操作可能已生效，应查询任务状态核对。退出设置页保持桥接运行，退出软件后桥接关闭；重启不会自动开启。重新开启时要更新 Hermes 的端口和令牌。

## 已完成的沙盒验证

本机 HTTP / stdio MCP 真实握手、工具发现、查询、暂停、恢复、重复请求去重、越权拒绝、令牌撤销，以及 API GET / POST、中文响应、网络失败不自动重试均有测试覆盖。隐藏 Electron 验证实际界面与本机服务的调用链路。

所有任务为合成夹具，没有向真实微信用户发送消息，没有调用付费模型。真实微信账号与具体第三方服务的兼容性需要对应账户配置后再验收；内部测试通过不等同于所有供应商已适配。

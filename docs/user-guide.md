# 文件驱动工作台使用说明

此文档对应 0.1.81。升级前请保存项目；旧项目可在设置中选择性导入，原始资料和历史记录保留，不自动恢复旧任务。

## 完成一次制作

1. 在设置中添加分析模型、视觉模型与生图模型。填写兼容 API 地址、模型 ID 和密钥；保存后可检查连接或单独验证能力。能力验证会实际调用对应 API。
2. 新建项目，在右侧分别上传产品和图需。参考图、培训文档、自定义资料按需添加。软件复制原件并解析正文、嵌图与页图；上传不会调用生图。
3. 在下方输入任务目标，选择“分析并制定方案”。可选择完整制作、单图或只出方案与提示词。
4. 阅读右侧“方案”和“图需”。图需表格可以修改共同风格、代表图位、尺寸、颜色、语言、准确文案、参考绑定、画面设计、提示词与检查项。只有必需内容完整后才能确认。
5. 点击“确认方案并生成样图”。默认生成一张代表样图并检查实际尺寸、可读性和画面要求；在图片面板查看实际图片、复核问题及输入版本。
6. 确认具体样图版本后，软件连续制作剩余图位。样图计入套图。单图失败不阻断其他图位。
7. 选择满意结果并采用。批量采用只影响选中版本。自动复核分为未发现问题、发现问题、无法判断，其意见不代替用户选择。
8. 导出仅包含当前图需下已采用的图片；交付清单逐图说明缺项，支持部分交付，同时可附带制作文档。

## 修改、恢复与未知结果

“修改方案 / 返修”需要选择当前图位、整套风格或新增图位。局部修改只允许修改选定图位；勾选“保存后返修”才会调用生图。只保存方案时停在文档阶段。共同风格修改会列出全部受影响图位，重新确认方案和样图。

图片面板保留每个候选版本。切换预览不会改变已确认或采用的版本。文件面板支持直接编辑、查看新旧内容和恢复历史；恢复也是新增版本。原件和执行结果不可覆盖。

暂停和退出会等待已有写入保存。重新打开后从未完成项继续；已有成图的检查单独恢复。结果未知时先“查询原请求”，不会重新发送。服务商无法查询时，用户在服务商后台核对并填写明确失败依据后，才可解除重试限制；之后仍需要明确点击重试。

## 资料库、Skill 与新任务

资产库、品牌库、提示词库支持分类、标签、正文、配套文件和历史版本。可从当前项目保存指定资料，再引用到其他任务。选用的 Skill 正文与配套资料参与分析和提示词编写，脚本文件不会执行。

“复用为新任务”复制产品、图需和文档的当前版本及引用，复用已有解析缓存。新任务不继承审批、采用或生图记录。更换产品请建立新项目并上传新产品依据；不要将旧产品档案当成新产品事实。

已有完整方案可作为图需上传。原文与来源保留；策划优先沿用，补齐执行参数和参考。符合结构的完整 JSON 方案会直接作为图需采用，上传本身不会批准生图。

## 本地文件与迁移

桌面工作空间位于 `%APPDATA%/Twin Stars Studio/file-workspace`，项目中的原始资料、可读资料、工作文档、制作结果分别保存，内容对象使用 SHA-256 校验。密钥保存在独立加密文件，不进入项目包。

设置中可以备份工作空间，并通过“查看本机备份”恢复为独立项目及资料库。恢复保留备份中的文件版本、已完成结果和确认记录，校验文件内容，保留当前项目及较新的调用记录；未完成请求先查询，不自动重发。密钥不进入备份，需保留原 Windows 用户的加密配置或重新填写。

项目资料包包含原件、可读内容、工作文档、全部版本和历史记录，导入为新任务，不继承旧审批。工作空间备份用于恢复既有制作进度；项目包与“复用为新任务”用于开展新任务。

旧工作空间可选择项目导入。软件先保存旧数据备份，再复制可用资料、图片、图需和对话，并导入三个库。旧画布、Max 和群聊只归档，不重新执行。旧项目只有提取正文或外链缺失时会列入迁移说明，需重新上传原件。

更新由用户选择“暂不更新 / 立即更新”；安装前保存并备份。备份失败时停止安装，不继续重启。

## 当前边界

工作文档支持 Markdown、JSON、TXT；不提供 Office 成果生成与双向同步。PDF、Office 文档、XMind、文本与图片等沿用本地解析器，旧 Office 格式通过打包的 LibreOffice 读取。PSD 仅可作为输入读取预览，不输出 PSD/PSB。

单份上传最多 128 MB；项目包导出累计最多 512 MB。超大资料需要拆分。模型协议和可输出尺寸依赖具体服务商；不符合尺寸的结果会标记问题，不能直接采用。部分服务商没有异步任务查询接口，未知结果需要人工核对。

# Twin Stars Studio 使用说明

适用：Windows x64 桌面版，按 2026-11-11 集成版本整理。界面入口以实际安装版本为准。软件简介见 [首页](../README.md)，安装包见 [最新版本](https://github.com/ThereisnoholidayonFriday/twin-stars-studio-releases/releases/latest)。

本页对应 0.1.68，包括统一项目流程、资料分类与复用、多方向确认、项目资料包、后台 PSD 编码、工具连接器和小型联网安装器。版本信息见[更新说明](release-notes.md)。

## 安装与准备

1. 发布页面提供联网和完整离线安装时，可优先选择约 0.32 MB 的 `Online-Setup.exe`，安装时下载完整程序；离线安装选择 `Twin-Stars-Studio-版本号-x64-Setup.exe`。后续在完整安装向导中选择目录。联网入口从 0.1.61 开始提供，详见[联网安装说明](online-installer.md)。
2. 打开软件，建立自己的项目。安装版不需要运行开发服务器或另装 Node.js。
3. 准备模型服务的接口地址、API Key、模型 ID；这些信息由你选择的服务商提供。
4. 本地导入、浏览、整理与部分图片处理可离线使用；AI 调用和联网研究需要网络及相应服务。

建议为原始资料保留独立文件夹。关联文件夹后，移动或删除源文件会影响重新读取，已经成功导入的本机副本仍可使用。不要把项目唯一副本只放在软件缓存中。

## 配置模型

打开 **设置与连接 → 模型服务 → 添加模型**：

1. 填写名称、服务地址、模型 ID 和 API Key，按服务要求选择协议及请求路径。
2. 勾选模型实际支持的能力：文本对话、图片理解、图片生成、图片编辑、局部重绘；一个模型可有多项能力。
3. 保存配置，再进行连接测试。
4. 在能力验证区选择一项能力，点击 **调用一次并验证**。看图/编辑需提供测试图片；局部重绘还需同尺寸、不透明的黑白蒙版，白色表示修改区域，黑色表示保留区域。
5. 将合适的模型添加到项目成员中；任务入口会按所需能力筛选。

**连接测试不等于能力验证。** 能力测试会真实调用服务，可能产生费用；“已验证”表示该请求获得有效响应，不保证成图质量、产品一致性或文案准确性。超时、额度不足和认证失败不能证明模型不支持该能力。

桌面版保存配置后使用当前 Windows 账户保护 API Key，重启后可读取。密钥不随项目 JSON 导出；换电脑需重新配置。浏览器开发预览仅保留会话密钥。不要把密钥写到提示词、连接器 URL 或导出的项目说明中。

## 项目与子项目

- 在项目库新建项目，选择对话、画布或对应制作入口。
- 项目及子项目的 **三个点** 菜单提供重命名、置顶、归档、删除等操作；归档和删除内容可在相应列表恢复。
- 删除与彻底删除含义不同；彻底删除前确认已备份，仍被其他子项目引用的共享素材会受到保护。
- ChatStars 与画布有独立的会话/画布内容。创建副本会产生独立项目，原内容与历史保留；副本的执行和确认状态需重新建立。
- 软件会自动保存；可用 **Ctrl+S** 显式保存，保存失败会提示。正常保存后不再常驻显示徽标。关闭窗口可能转入后台，彻底退出使用应用提供的退出入口。归档项目可从设置中管理。

## ChatStars：对话与生成

桌面版 ChatStars 使用浅色界面，画布使用深色界面；从画布打开设置时保留深色。模型回复支持标题、列表和表格，底部提供复制与重新生成；重新生成会核对原模型和原始引用，可能产生新的调用费用。

1. 打开项目，添加项目成员或选择当前模型。
2. 输入任务，选择 **对话** 或 **生图**；同一多能力模型可以承担不同任务。
3. 上传资料，或从 **查看全部 / 选用项目素材** 打开素材窗口。
4. 选中图片和文档，点击 **用于本轮对话**；检查输入区中的引用，再发送。
5. 生图前检查模型、比例、分辨率与数量。完成后可以保存原图、编辑或送到画布。

引用已保存资料通常无需重复上传原文件；关联文件夹的资料分析可复用已有读取记录。新的问题、定向看图或独立审核仍可能调用模型，不能把缓存理解为所有后续任务都免费。

点击停止会停止本机等待或后续调度；外部服务可能已经接收请求，不能保证服务端取消或退费。遇到状态不明的请求，先查看任务记录，避免反复提交相同生图任务。

## 无限画布

### 导入与连接

- 将图片或 TXT 文件拖入画布，也可使用导入入口；图文混合导入可一次撤销。
- 右上角“项目素材”可搜索并多选已有图片和文档，再点“添加到当前画布”；图片复用已有素材，文档作为文本节点加入，整批可一次撤销或重做。
- 双击空白区域创建节点。从端口拖线到另一节点建立输入关系；拖到空白处可选择兼容节点并自动连接。
- 生成节点可以使用上游连接的文本提示词，不必在节点中重复填写。
- Shift 多选图片后可创建图片组；组输出口可将整组参考传给下游。
- 双击连线断开，Ctrl+Z 恢复。输入变化后，旧结果会保留并显示历史/失效状态。

### 生成与尺寸

先检查提示词、参考图、模型、数量、比例和 1K/2K/4K 分辨率，再运行节点或所选流程。

**Auto 规则**：提示词中的尺寸比例 → 实际输入顺序的第一张参考图比例 → 由模型决定画幅。分辨率档位参与计算目标像素；主参考标记不改变上述输入顺序。提示词中写入像素数，不代表所有模型都会严格按该像素数返回。

**再次生成**使用上一张实际图片尺寸与保存的执行快照；更换了上游提示词后，希望按新输入运行时，应执行对应生成节点。尺寸不符合要求的结果会保留并提示，不能把提示中的目标尺寸当成实际输出尺寸。

生成进度卡与来源连线在运行时显示。取消批量任务会保留已完成图片，未完成部分不会冒充成功；下载会使用不同文件名，减少覆盖原文件。

### 常用操作

| 操作 | 方法 |
| --- | --- |
| 保存 | Ctrl+S |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |
| 多选 | Shift 点击 |
| 框选 | Ctrl＋左键拖动 |
| 追加/取消框选 | Ctrl+Shift＋拖动 |

图片显示使用缩略预览；生成、保存和下载仍使用原图。大规模节点、长文档和高分辨率图层仍可能占用较多内存。

## 资料、资产库与品牌

### 项目资料

资料分为产品、图需、参考、其他。自动分类仅根据名称、目录和用途提示整理，不证明产品事实；可手动修正分类或恢复自动分类。已有明确的手动用途优先，生成作品不会自动成为产品身份依据。

在项目素材中浏览图片和文档，搜索名称或来源，翻页选择。可预览原图/正文、下载原文件、引用、编辑或在画布打开。

**关联文件夹**读取你选择的本机目录。根据入口选择产品资料、品牌规范或参考资料分类；总管启动及重新读取前会把文档正文、原文件与图片提取到项目。手动入口提供 **提取到项目 / 提取全部资料到项目 / 更新资料**。源文件变化后使用更新资料，打开窗口本身不代表强制重扫所有文件。

当前 Office 原文件（xlsx/docx/pptx）上限为 256 MB，其他格式默认 50 MB；手动导入批次上限为 512 MB / 250 份。Office 还受解压内容、图片数量等保护限制，低于文件体积上限也可能因为内容规模被拒绝。复杂版式与 OCR 可能有警告，请检查读取范围和原始文件。

### 读取中断与恢复

- 资料面板区分已读、未读、失败位置和保存的证据记录。
- 失败后选择 **补读未完成资料**；已成功的片段和子段会尽量复用，避免从头开始。
- 暂停时先等待 **暂停中** 完成，当前调用保存后再恢复。
- 524/504 等网关超时需要检查服务状态。连续同样超时可更换稳定服务或联系服务商；不要反复点击重新开始。
- 不支持、未解析或缺失的资料不能当作已读完成。原文证据与摘要分开保存，摘要不等于完整原文。

### 公共资产库

按 **分类 → 文件夹 → 标签** 组织图片，搜索可覆盖这些信息。支持收藏、添加到项目、文件夹调用、单项及多选导出。公共资产与项目副本独立，修改一份不代表同步修改所有项目。

文件夹调用会保留采用的版本；查看新增、更新、移除和不可用项目后，再明确采用新版本。导出原文件可查看进度、取消或重试失败项，部分失败会附清单；单次导出受 512 MB 上限保护。

### 品牌规范

新建品牌卡片，上传品牌手册、字体包和标志文件。可使用具备相应能力的模型总结手册中的排版、颜色等规范，先预览并核对来源，再采用。上传字体文件不等于将字体安装到 Windows；AI 总结也不能代替检查原始品牌要求。

规则来源可查看原文、位置和版本。更换原文件后应重新核对旧总结，复制或迁移品牌也需要确认引用的原文件已随资料包带入。

## 套图制作与项目总管

在项目主对话中描述制作需求，上传产品资料、需求、参考或训练资料并标明用途。普通对话和手动生图不会自动启动 Max 套图制作。Max 任务在同一对话中展示阶段进度、追问、确认卡和作品；任务记录可查看来源、执行情况与未完成范围。

调用内置 Max Skill，或输入“按项目资料启动完整流程”，会进入同一真实流程。需要指定主导时只 @ 一个模型；识图、生图和独立审核仍按已配置角色分工。主对话显示当前状态、必要确认、异常与作品；详细来源、任务和记忆记录移到项目设置中查看。

逐张图片的尺寸按图需执行，不再用统一默认宽高代替。缺少或冲突的尺寸需补充确认。资料事实和解析结果在本机复用，来源、模型或协议变化时失效；这不能保证所有后续调用免费。批量制作并发受已有模型设置和最多三项的上限控制，不自动提高服务商并发或追加尝试预算；未知结果先核对原请求，不自动重发。

资料不足时分批回答问题，每批最多三项；再确认生成路线、代表图、尺寸与源文件范围。方向说明和实际代表图一起展示，可选择一个、两个或全部三个方向，最后明确提交。勾选草稿不代表批准制作，资料或结果变化后需要重新确认当前版本。定向修订可以只修改指定方向或代表图，其他方向的结果保留。追加尝试与源文件输出也需确认对应范围。

Lovart 路线只在配置并通过连接探测后提供，不可用时不会静默改用其他服务。交付区展开当前范围的真实作品；资产库的“可交付作品”不包含演示、旧版本或未审核完成内容。

- 第二步竞品链接和参考资料允许选填；没有填写不等于后续必要研究全部取消。
- 项目资料能提供的事实应优先从资料读取；缺失或冲突时补充当前项目要求。
- 各阶段完成后查看结果，使用确认或修订。修改范围或资料后，旧确认不能自动批准新结果。
- 制作在确认的范围与尝试预算内执行，失败和返修有记录；审核失败不能当成合格交付。
- 尝试预算是调用数量限制，尚无人民币金额硬上限。界面只累计服务明确返回的同币种费用，未知费用不表示免费。
- 资料长、图片多时，解析、看图和控制文件生成可能较慢；观察进度与失败位置，优先恢复原任务。

该流程已接入真实模型适配器及本地工具，但一条模拟流程跑通不等于真实商业套图必然合格。产品结构、文案、尺寸和审核结论需要逐项核对。

## 规则与学习

在 **设置与连接 → 项目** 查看规则、学习、记忆和检查记录。新项目默认启用本地学习，已有项目明确关闭的设置会保留。系统记录明确的用户反馈，并按项目、同品牌或个人范围使用；普通上传文件、网页内容和模型猜测不会直接成为用户规则。可关闭学习、核对来源或撤回规则。内置 Max 基线规则的自动启用有独立记录，不冒充用户手动批准。

新任务冻结当前已确认规则。已有任务先暂停，再选择 **重新读取更新资料与配置**。新增规则不会偷偷改变正在执行的任务；撤回规则后，旧任务需更新资料才能继续。

在“整理反馈”中保存手工候选不调用模型；“用策划模型整理候选”会使用已配置模型并可能计费，生成的候选仍需确认。“执行规则”提供来源和本地搜索，“检查记录”展示规则快照及结果。

可备份和恢复规则库；恢复前需暂停任务并核对在途请求。规则库位于应用数据目录的 agent-learning/knowledge.sqlite，项目资料包不包含完整规则库，迁移前需另行备份。

这是本地规则与反馈管理，不修改模型权重。程序检查尺寸、参考图及记录版本，视觉要求仍依赖实际看图审核；普通聊天和手动生图保留原来的功能边界。

## 图片编辑与导出

打开图片的编辑入口：

- 可编辑图片/文字图层，调整位置、尺寸、显隐与层级，添加空白图层，裁切与本地调色。
- 快捷编辑、去背景、拆分图层、改文字、智能消除等 AI 操作需要支持图片编辑的模型；局部处理还取决于蒙版支持。
- 多角度提供主体/摄像头参数与预览，实际新视角结果取决于模型，不能从一张参考图保证恢复真实背面结构。
- 保存会生成新版本，原版本保留。PNG 为平面结果；PSD/PSB 用于保留独立图层和可编辑文字。
- PSD/PSB 导出有内存保护，编码在后台进行，可查看进度或取消；图层或尺寸过大时需减小规模。当前尚未完成真实 Photoshop 打开验收，交付客户前请实际打开检查。

## 保存、备份和换电脑

软件数据主要位于当前 Windows 用户的 `%APPDATA%\Twin Stars Studio`，安装目录和数据目录不是同一个目录。

**项目导出不是完整软件备份。** 修复版的顶部导出按钮生成 `.twinstars.zip` 项目资料包，包含项目结构、图片、消息、图层、解析文本以及本机可读取的原始文档，附件逐项校验。未找到的原文件会提示并列入包内清单；请另存源目录。后台任务检查点、目录授权和 API Key 不在包内。

旧 `.twinstars.json` 仍可导入，但不含原文件，即使已经有解析正文。修复版会明确提示原文件缺失；不要把 JSON 当作完整附件备份。导入资料包后任务保持暂停，需要重新关联目录和配置模型。

换电脑或重装前：

1. 显式保存项目，导出需要迁移的项目资料包，核对缺失文件提示。
2. 另行复制原始资料文件夹，下载必须保留的原文件与作品。
3. 完全退出软件后，另存完整的应用数据目录作为本机恢复备份；不要在正在写入时直接覆盖该目录。
4. 新电脑安装软件、导入项目并重新关联资料、配置模型密钥。完整目录备份主要用于同账户恢复，不保证跨账户密钥迁移。

版本更新建立的恢复点用于保护当前工作区，不是异地备份，也不会自动把项目上传到 GitHub。不要手工删除 IndexedDB 或后台资料缓存来“加速”。

修复版可在 **设置与连接 → 工作空间 → 本机空间清理** 检查和回收未引用的大对象。当前项目和全部恢复点仍引用的数据会保留；清理不删除原文件资料库或源目录。

## 版本更新

默认启动约 6 秒后检查更新，持续运行时约每 15 分钟检查；可在 **设置与连接 → 版本与更新** 手动检查或关闭自动检查。

发现新版会显示版本号和更新内容：

- **暂不更新**：本次运行不再重复提示同一版本，可稍后从设置页更新；重启或发现更高版本后可能再次提示。
- **立即更新**：下载后保存并备份项目，再重启安装。下载、备份或安装失败会显示错误，不能继续强行重启。

软件关闭、离线或关闭自动检查时不会实时弹窗。普通源码提交不会分发新版本，只有明确发布的版本才进入更新通道。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 模型连接成功但不能出图 | 核对能力、协议、模型 ID、参考图/蒙版支持，运行对应能力测试 |
| 资料一直等待或返回 524 | 查看失败文件与子段；保留成功记录，恢复未完成部分，检查服务商状态 |
| 项目素材正在加载但想退出 | 修复版可按关闭或 Escape；已启动的后台读取继续，可稍后重新打开 |
| 生图尺寸与要求不同 | 核对实际尺寸与提示；选择兼容模型或明确的本地重采样，不把拉伸当成重新生成 |
| 换电脑后不能打开原文档 | JSON 没有携带完整原文件；补充原文件并重新关联 |
| 删除图片后磁盘占用未明显下降 | 在设置的“本机空间清理”检查未引用大对象；恢复点仍引用的数据会保留 |
| 更新没有弹窗 | 检查网络、自动检查设置、是否曾选择暂不更新，或手动检查 |
| PSD/PSB 导出慢或拒绝导出 | 减少尺寸/图层；大文件导出仍有性能限制 |

### 资料读取与暂停恢复

使用“按关联文件夹中的产品资料和图需文档启动完整流程”可直接进入制作流程。读取完成后先确认制作选项，再进入方案和制作；首次更新资料也保留此确认。暂停后点击继续会恢复原确认卡，仍需你亲自确认，不会替你批准制作。

空文件无法作为制作资料。新导入会给出提示；历史项目若出现空附件，请在项目素材中移除空附件或重新上传有效文件，然后发送“更新资料”。需要读取文件夹时使用“关联文件夹”。

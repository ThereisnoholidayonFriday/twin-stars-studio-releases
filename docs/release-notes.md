# Twin Stars Studio 0.1.62

## 规则与学习

- 项目总管新增“规则与学习”：载入 14 条 Max 规则候选，逐条编辑确认或在当前项目批量采用；默认关闭，按项目启用。
- 支持手工整理反馈、项目/同品牌/个人范围、撤回规则、本地经验检索和检查记录。可选“用策划模型整理候选”会调用已配置模型并可能计费，候选仍需确认。
- 新任务冻结已确认规则；已有任务暂停后可重新读取资料与配置。新增规则不会自动改变运行中的任务，撤回或来源失效会阻止旧快照继续执行。
- 发送图片请求前校验实际参考图、提示词和批准尺寸；审核绑定当前图片与规则版本，导出前再次检查。创作者自检不替代独立审核。
- 新增本地规则库备份与恢复，重复反馈请求不会自动重发；本地语义检索不可用时退回关键词检索。

## 画布与性能

- 从项目素材单张或批量加入画布时，按图片资产/内容和文档来源跳过重复项；只新增未加入的素材，全部重复时不增加撤销记录。范围为当前子画布，已有重复节点保留。
- 修复大图片参与多次拖动后撤销历史反复序列化原图造成的卡顿，保留最多 30 步撤销/重做及元数据预算。
- 项目总管状态轮询缓存轻量显示数据，任务文件变化后失效，减少重复读取和解析大型任务记录。

## 安装与说明

- 继续提供小于 50 MB 的联网安装入口，安装时下载并校验约 620 MB 的完整程序；保留离线包。准确大小以附件为准。
- 更新弹窗显示本说明，保留“暂不更新 / 立即更新”；安装前保存并备份项目。
- GitHub 使用说明补充规则确认、启用、撤回、恢复及计费边界。学习功能是本地规则与反馈管理，不修改模型权重，不保证真实成图质量；真实模型试点及 Photoshop 实机验收仍未完成。

# Twin Stars Studio 0.1.61

## 小型联网安装包

- 新增小于 50 MB 的 Online-Setup.exe，首次下载约 0.32 MB；安装时联网下载完整程序，校验通过后才开始安装。保留完整离线安装包。
- 精简 Windows x64 不使用的运行库和 Office 附带资料，保留文档转换、OCR、字体及离线语义检索。完整程序仍约 617 MB，不是 50 MB 的离线软件。
- 更新弹窗显示更新内容，继续由你选择“暂不更新 / 立即更新”；安装前保存并备份项目，失败不继续重启。

## 项目流程与资料恢复

- 整理项目流程、阶段内容和项目记忆入口；查看其他阶段不会推进任务，保留工作记录与恢复入口。
- 交付列表展示需求、文案、提示词、审核和尝试记录，区分当前结果与旧结果。
- 区分模型认证、解析、资料读取和存储故障，给出对应恢复说明；资料结果写入失败时保留待写日志，恢复优先复用已完成结果。
- 修复 Windows 文件锁导致的检查点写入问题，减少重复读取；来源路径备注不再被当作文件夹访问授权。

## ChatStars、无限画布与图片编辑

- 会话切换保留草稿、引用和消息编辑状态；同名文档按实际文档 ID 引用，避免误选。
- 长对话分批渲染，保留全部历史；画布撤销/重做随子画布保存，限制历史占用。
- 画布右上角新增“项目素材”入口，复用素材搜索和多选；图片与文档可批量添加到当前画布，一次撤销/重做，并定位新节点。
- 统一项目素材入口，说明关联文件夹、导入副本与来源备注的区别；改善深色主题可读性。
- 修复图片编辑器异常缩放、零尺寸容器及大画布适配；PSD 保留画布外像素和负坐标图层，编码在后台进行并支持进度与取消。
- 界面崩溃后由用户选择恢复，不自动循环重试或重发模型请求。

## 素材库、品牌资料与备份

- 素材收藏使用统一选择面板；详情展示版本及搜索命中原因。
- 文件夹资料显示新增、更新、移除和不可用状态，由用户确认采用新版本，保留项目内编辑。
- 支持按分类和文件夹导出原始图片、文档，提供进度、取消、部分失败清单及失败项重试。
- 品牌规则展示原文来源、位置和版本，区分人工资料与 AI 总结；替换原文件后使旧总结失效，修复复制和迁移时的来源映射。
- 新增包含原始附件的 .twinstars.zip 项目资料包，导入时校验文件完整性，失败可回退；普通 JSON 仍不包含全部附件。
- 空间清理检查项目和备份引用，减少误删仍在使用的文件；改善全文搜索响应。

## 模型调用与工具连接

- 预检、调用登记和实际请求保持用户批准的 1K/2K/4K 尺寸一致；Lovart 维持其流程约定的 2K。
- 限制超大图片及动画解码占用，流式读取超限即停止，不以静默缩图替代原图。
- 停止任务时停止新调用及本地等待，保留服务端结果未知的记录，防止重复提交；不承诺撤销已发送的远端任务或费用。
- 费用只显示服务实际返回的金额和币种，区分零费用与未知费用，不混加不同币种。
- 新增手动 MCP（HTTP/stdio）工具发现与确认调用，以及固定地址 HTTP API GET/POST；忙碌时可停止等待并断开，忽略迟到结果，不自动重试写操作。
- 新增 Hermes 微信本机任务桥接：按项目授权查询、暂停及可选恢复已有任务。只监听本机回环地址，令牌保存在会话内存，不自动开放公网。

## 使用说明与验收边界

- GitHub 简介、使用说明、连接器配置与联网安装说明同步更新。
- 本轮使用内部沙盒、模拟模型和隔离项目验证。真实付费模型整套商业成品验收、真实微信通道联调，以及 Photoshop 实际打开、编辑并重存 PSD/PSB 保留为待实机验收。
- 生成预算限制调用数量；尚未实现人民币金额硬上限。完整离线安装体积及安装后磁盘占用不会因联网安装入口而降至 50 MB。
